ОБЪЯСНЕНИЕ КОДА (index.html, style.css, script.js)
==================================================

Что делает сайт: магазин предметов Deadlock. Товары и отзывы грузятся с
сервера. Можно открыть карточку товара, посмотреть видео, положить товар
в корзину и оставить отзыв.

Главная идея (её стоит уметь рассказать своими словами):
  данные приходят с сервера -> лежат в массивах (items, comments, cart)
  -> функции рисуют HTML из этих массивов -> клики вызывают функции,
  которые меняют массив и перерисовывают страницу.


1. ПЕРЕМЕННЫЕ В НАЧАЛЕ script.js
--------------------------------
const API = '...'      адрес сервера (const - менять нельзя)
let items = []         товары
let comments = []      отзывы
let cart = []          корзина
let current = null     товар, открытый сейчас в окне (null = пока никакого)

[] - пустой массив (список). let - значение менять можно.

Ниже const list, itemWindow и т.д. - элементы страницы, найденные по id
через document.getElementById. Мы находим их один раз, чтобы потом
менять их содержимое.


2. loadData() - ЗАГРУЗКА С СЕРВЕРА
----------------------------------
async / await   fetch идёт на сервер, это не мгновенно, поэтому пишем
                await ("подожди ответ"). await работает только внутри
                async-функции.
response.json() превращает ответ в обычный массив объектов.
for (...)       цикл, пробегает по data по очереди (i = 0, 1, 2 ...).
Сервер отдаёт товары и отзывы вперемешку, у каждого есть поле type.
Если type === 'product', кладём в items, иначе в comments
(push = добавить в конец массива).
try / catch     "попробуй; если ошибка - выполни то, что в catch".
                Чтобы сайт не ломался, если сервер не ответил.
Последняя строка файла loadData(); запускает всё при открытии страницы.


3. showItems() - КАРТОЧКИ ТОВАРОВ
---------------------------------
Цикл собирает кусок HTML для каждого товара в строку html.
Обратные кавычки ` ` позволяют вставлять переменные через ${...},
например ${items[i].price} превратится в цену.
onclick="openItem(${i})" - клик по карточке открывает окно товара.
В конце list.innerHTML = html вставляет всё на страницу.


4. КОРЗИНА
----------
addToCart(item)  кладёт товар в cart и обновляет корзину.
removeItem(i)    cart.splice(i, 1) удаляет 1 элемент с номером i.
showCart()       показывает число в кнопке "Корзина", рисует список и
                 считает сумму sum. Если корзина пуста - пишет об этом
                 и выходит (return).
                 Number(...) превращает цену в число, чтобы цены
                 складывались, а не склеивались как текст.
openCart()       обновляет корзину и открывает окно.
Кнопка "Купить" в корзине просто показывает alert (всплывающее окно).
Купить товар можно только в окне товара.


5. ОКНО ТОВАРА, ВИДЕО, ОТЗЫВЫ
-----------------------------
openItem(i)      запоминает товар в current, заполняет окно (название,
                 цена, описание, картинка), показывает видео и отзывы,
                 чистит форму и открывает окно (добавляет класс is-open).
                 .textContent - записать обычный текст,
                 .innerHTML - записать HTML.
Видео            у товара на сервере должно быть поле video со ссылкой
                 на YouTube (вида youtube.com/watch?v=...).
                 .replace('watch?v=', 'embed/') превращает ссылку в
                 вид для встроенного плеера. Если поля video нет,
                 блок прячется (display = 'none').
                 Если видео пишет "Ошибка 153" - сайт открыт как файл.
                 Открывай через Live Server (расширение VS Code) или
                 выложи на хостинг.
showComments()   идёт по всем отзывам и выводит только те, где
                 comments[i].product совпадает с названием открытого
                 товара. Если таких нет - "Отзывов пока нет".
sendComment()    1) берёт имя, текст и оценку из формы
                    (.trim() убирает пробелы по краям);
                 2) если имя или текст пустые - пишет сообщение и
                    return (дальше не идём);
                 3) собирает объект newComment в том же виде, как
                    отзывы на сервере;
                 4) fetch с method: 'POST' отправляет данные на сервер
                    (раньше был GET - получение);
                    JSON.stringify превращает объект в текст;
                 5) сервер возвращает сохранённый отзыв, добавляем его
                    в comments и обновляем список.
closeAll()       убирает класс is-open у обоих окон и очищает видео
                 (чтобы звук не продолжал играть).

Про защиту: текст отзывов вставляется как есть. Это нормально для
учебного проекта, но на настоящем сайте так делать нельзя: если
кто-то напишет в отзыве HTML-код, он выполнится на странице.
Это можно упомянуть преподавателю как "что бы я улучшил".


6. КНОПКИ В КОНЦЕ script.js
---------------------------
element.onclick = функция;
  "Когда нажмут на этот элемент, выполни эту функцию".
  - modalBuyBtn   -> добавить открытый товар в корзину
  - reviewSendBtn -> отправить отзыв
  - cartBtn       -> открыть корзину
document.querySelectorAll('.close') находит ВСЕ крестики (в обоих
  окнах), а цикл вешает на каждый closeAll.
Кнопки внутри карточек и корзины создаются в шаблонах, поэтому у них
onclick написан прямо в HTML-строке: openItem(i), removeItem(i).


7. ПРО document: МОЖНО ЛИ ЕЩЁ ПРОЩЕ?
-----------------------------------
В коде уже используется document.getElementById - это и есть основной
способ "достать" элемент со страницы.
Можно создавать элементы через document.createElement и вставлять их
через appendChild, но тогда для каждой карточки нужно писать много
строк (создать тег, записать текст, вставить внутрь, добавить в
страницу). Шаблон со строкой HTML и innerHTML короче и читается
проще, поэтому оставлен он.


8. СТИЛИ (style.css)
--------------------
Стиль чёрно-белый: чёрный фон, белый текст, серый (#999) для
второстепенного текста. Заголовки с засечками (Georgia). Изюминка:
картинки в карточках чёрно-белые (filter: grayscale(1)), а при
наведении на карточку появляется цвет.
Кнопки белые, при наведении цвета меняются местами (чёрная с белым).

Что нужно знать про CSS:
- * { margin: 0; padding: 0; box-sizing: border-box } - сброс
  стандартных отступов, чтобы размеры считались проще;
- display: grid + repeat(auto-fill, minmax(220px, 1fr)) - карточки
  сами перестраиваются в столбцы под ширину экрана;
- display: flex - элементы выстраиваются в ряд (класс row, шапка);
- .modal скрыт (display: none), а .modal.is-open показан - так JS
  открывает и закрывает окна, добавляя и убирая класс is-open;
- position: fixed; inset: 0 - окно растягивается на весь экран;
- :hover - стиль при наведении мыши.


ВОПРОСЫ, КОТОРЫЕ МОГУТ ЗАДАТЬ
-----------------------------
- Чем let отличается от const? let менять можно, const нельзя.
- Что такое async/await? Ждём ответ сервера, не зависая.
- Зачем try/catch? Чтобы сайт не ломался при ошибке сети.
- Чем GET отличается от POST? GET - получить данные, POST - отправить.
- Как открывается окно? JS добавляет класс is-open, а CSS его показывает.
